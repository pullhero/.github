# PullHero: AI-Powered Agentic Code Assistant Tools

Welcome to PullHero, a suite of AI-driven tools designed
to enhance your development workflow by automating code improvements,
code reviews, general inquires about the source code, and documentation generation.

This project mission is to streamline your coding processes,
allowing you to focus on building great software.

## Features

- **Automated Code Reviews**: Utilize advanced AI models
to perform intelligent, context-aware code reviews,
providing actionable feedback and approval recommendations.

- **Automated Documentation Generation**: Leverage AI to automatically
generate comprehensive documentation from your codebase, ensuring accuracy and consistency.

- **Automated Code Improvements**: Receive intelligent code suggestions
and improvements to enhance code quality and maintainability.

- **Know-it-all about your repositories**:  Get fast, accurate, and smart answers about your code base.

## Repositories

- [pullhero/agent](https://github.com/pullhero/agent): Contains the GitHub actions agent with access  to all the features.

- [pullhero/python-client](https://github.com/pullhero/python-client): Houses the automated documentation, code review, code improvement and consulting agent.
